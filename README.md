# Wai Yan Htet Aung — Portfolio

A responsive, single-page professional portfolio based on the supplied résumé.

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/profile.jpeg` — portrait extracted from the supplied résumé
- `assets/Wai-Yan-Htet-Aung-Resume.pdf` — downloadable original résumé

## Publish on GitHub Pages
1. Create a repository (for example `wai-yan-portfolio`).
2. Upload all files and folders from this package to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. Wait for the published URL shown in GitHub Pages.

No build tools are required. Google Fonts are optional; the page has sans-serif fallbacks.
